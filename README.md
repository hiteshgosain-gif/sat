# Road to 1600

Static, self-contained SAT prep site. Everything the page needs is in `index.html` (inline CSS and JavaScript). `resources.json` is the supporting resource catalog.

**Live site:** https://hiteshgosain-gif.github.io/sat/

Practice progress, practice-test history, and missed questions are saved in the browser’s `localStorage`. They stay on this device and in this browser; clearing site data or switching browsers starts fresh.
